# しぜんの かくれんぼ ずかん

小学 1 年生の国語「うみのかくれんぼ」（光村図書『こくご 一上 かざぐるま』）で、
**自分で調べた生きものの かくれ方を、教材文と同じ形で書く**ための Web 図鑑です。

→ 先生向けの説明は [for-teachers.html](for-teachers.html)（公開ページ）に書いてあります。

## このアプリが引きうけているところ

単元のおわりに、子どもは「じぶんで えらんだ 生きものの かくれ方」を
教材文と同じ形で書きます。本来は図書室の図鑑から材料を集めるところです。
**そこを置きかえる**ので、3 文だけでなく、1 ひきにつき
すみか・大きさ・たべもの・いつ見られるか・なかま・からだのようす・
もっとしりたい まで持っています。

8 つのばしょ（うみ／うみべ・いそ／かわ・みずべ／くさむら／もり・はやし／
つち・おちば／ゆき・こおり／さばく・かわら）から、生きもの **73 ひき**。

## 教材文の型

| | 欄 | 形 |
| --- | --- | --- |
| ① どこに | `placeS` | 「〇〇が、〜に かくれて います。」 |
| ② からだの とくちょう | `bodyS` | 「〇〇は、〜を もって います。」「〜ことが できます。」 |
| ③ どのように かくれるか | `howS` | 「〜て、かくれます。」 |

②（もっているもの＝体のつくり）と ③（すること＝かくれ方）の区別が、
この単元でいちばんつまずくところです。公開されている指導案が
どれもそう書いているので、カードでも入力欄でもこの 2 つを分けてあります。

画面の色分けは、公開されている指導案のワークシートにそろえました
（名前＝青 ／ どこに＝赤 ／ からだのつくり＝黒 ／ かくれかた＝きいろ）。

## 中身をどこで直すか

**`data/animals.js` を手で直さないでください。** 組み立てたものです。

| 直すもの | 直す場所 |
| --- | --- |
| 生きものの文 | `content/animals/<ばしょ>.json` |
| 写真（ライセンス・作者・出どころ） | `content/photos.json` |
| ばしょ・かくれ方の一覧 | `content/places.json` / `content/kinds.json` |

直したら組み直して、**組み上がったものもコミットします。**

```bash
node tools/build-animals.mjs     # content/ → data/animals.js
node tools/build-credits.mjs     # data/animals.js → credits.html
node tools/build-sw.mjs          # 配信物の中身 → sw.js の版（いちばん最後）
```

## 検査

```bash
node --test tools/*.test.mjs        # 検査そのものの単体テスト
node tools/build-animals.mjs --check
node tools/check-data.mjs           # 文の型・学年の漢字・写真のライセンス
node tools/check-no-external.mjs    # 外から読み込んでいないか（Zero-CDN）
node tools/build-credits.mjs --check
node tools/build-sw.mjs --check     # いちばん最後。直し終わってから

# 正本とのずれ（ポータルを隣に置いて走らせる）
node ../GIGAyama.github.io/standards/check-drift.mjs \
     --standards ../GIGAyama.github.io/standards
```

⚠️ **組み立てる道具は、CI では `--check` だけを呼びます。**
`build && check` の順に走らせると、build が先に生成物を上書きして
ずれが素通りします（2026-08-28 に艦隊の 10 本すべてで起きた形）。

⚠️ **`build-sw.mjs` はいちばん最後。** SW の版は配信物の中身から作るので、
通したあとに 1 文字直すだけで合わなくなります。手元では緑のまま、CI で赤くなります。

## 決めてあること

- **教科書の本文は 1 文も入れていません。** すべて書きおろしです。
- **漢字は 1 年生の 9 月までのものだけ。** それ以外はひらがな。
  `tools/check-data.mjs` が 1 ひきずつ見張ります。
- **写真は Wikimedia Commons の、だれでもつかえるライセンスのものだけ。**
  リポジトリの中に落として自分のドメインから配ります（ホットリンクしません）。
  CC BY / CC BY-SA / GFDL は作者とライセンスを出すのが条件なので、
  1 枚でも欠けたら `check-data.mjs` と `build-credits.mjs` が落とします。
- **生成した画像は 1 枚もつかっていません。** 本物でないすがたを図鑑として
  見せないためです。
- **数は、2 つ以上の出どころでそろったものだけ。** そろわなかったときは
  数を書かず、くらべるものや言い方であらわしています。
  しらべたときの URL は `sources` に入れて、生きもののページの下に出します。
- **個人情報を 1 つも集めません。** 名前を入れる欄はなく、書いた文は
  その端末の localStorage だけに残ります。
